# La Página de Daniel DB

Web de artista de **Daniel DB**: escritor, músico, guionista y científico de datos.

👉 **https://danielteniente.github.io/**

Una página personal al estilo de 1998, con humor de *Los Simpson* y *Futurama*, textos de no ficción y algún que otro minijuego. Sin imágenes: todo es texto, juegos y easter eggs.

Hecha a mano con HTML, CSS y JavaScript, sin frameworks, y publicada en GitHub Pages.
